# 第一次作业：HTML 表单与表格综合练习

## 文章导读
本篇是前端第一次作业，通过两个 HTML 页面练习**表单控件（input、radio、checkbox、select、textarea、button）**与**表格布局**的综合运用。作业包含「用户注册」表单和「工商银行电子汇款单」两个案例，适合 HTML 基础入门的读者。

## 一、作业说明
本作业共两个页面：
1. **作业1**：制作一个用户注册表单，使用表格进行布局
2. **作业2**：制作工商银行电子汇款单，使用表格展示回单信息

## 二、作业1：用户注册表单
使用 `<table>` 布局，配合多种表单控件实现用户注册界面。

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>作业1</title>
</head>
<body>
    <table border="1px" width="300px" height="250px" align="center">
        <tr>
            <td colspan="2" align="center" height="25">用户注册</td>
        </tr>
        <tr>
            <td width="100px" align="right" height="25">用户名</td>
            <td width="200px">
                <input type="text" name="username" id="username" value="" width="15" maxlength="20">
            </td>
        </tr>
        <tr>
            <td align="right" height="25">密码</td>
            <td>
                <input type="password" name="username" id="Userpass" value="" width="15" maxlength="20">
            </td>
        </tr>
        <tr>
            <td align="right" height="25">性别</td>
            <td>
                <input type="radio" name="sex" value="1" checked>男
                <input type="radio" name="sex" value="2">女
            </td>
        </tr>
        <tr>
            <td align="right" height="25px">爱好</td>
            <td>
                <input type="checkbox" name="like" value="xie">写作
                <input type="checkbox" name="like" value="ting">听流行音乐
                <input type="checkbox" name="like" value="ti">运动
            </td>
        </tr>
        <tr>
            <td align="right" height="25">省份</td>
            <td>
                <select name="province">
                    <option value="shannxi" checked>陕西省</option>
                    <option value="hainan">海南省</option>
                    <option value="shandong">山东省</option>
                    <option value="hunan">湖南省</option>
                </select>
            </td>
        </tr>
        <tr>
            <td align="right">自我介绍</td>
            <td height="75">
                <textarea name="intro" cols="30px" rows="5" placeholder="这家伙很神秘"></textarea>
            </td>
        </tr>
        <tr>
            <td colspan="2" align="center">
                <button type="send">提交</button>
                <button type="reset">重置</button>
            </td>
        </tr>
    </table>
</body>
</html>
```

**涉及的表单控件：**

| 控件 | 标签 | 说明 |
|---|---|---|
| 文本框 | `<input type="text">` | 输入用户名 |
| 密码框 | `<input type="password">` | 密码不可见 |
| 单选框 | `<input type="radio">` | 性别二选一，`name` 相同为一组 |
| 复选框 | `<input type="checkbox">` | 爱好可多选 |
| 下拉列表 | `<select>` + `<option>` | 省份选择，`checked` 设默认项 |
| 多行文本 | `<textarea>` | 自我介绍 |
| 按钮 | `<button>` | 提交、重置 |

## 三、作业2：工商银行电子汇款单
使用表格展示汇款回单的各类信息，包含合并单元格（`colspan`、`rowspan`）。

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>作业2</title>
</head>
<body>
    <div style="border: 0px">
        <h4>工商银行电子汇款单</h4>
    </div>
    <div style="border: 1px;">
        <table border="1px" width="800px" height="200px" cellspacing="0px">
            <tr>
                <td colspan="2"><b>回单类型</b></td>
                <td>网上转账汇款</td>
                <td colspan="2"><b>指令序号</b></td>
                <td>HQH0000000000000013878172</td>
            </tr>
            <tr>
                <td rowspan="4"><b>收款人</b></td>
                <td>户名</td>
                <td>老牟</td>
                <td rowspan="4"><b>付款人</b></td>
                <td>户名</td>
                <td>老刘</td>
            </tr>
            <tr>
                <td><b>卡号</b></td>
                <td>000000000001</td>
                <td><b>卡号</b></td>
                <td>000000000002</td>
            </tr>
            <tr>
                <td>地区</td>
                <td>南京</td>
                <td>地区</td>
                <td>杭州</td>
            </tr>
            <tr>
                <td><b>网点</b></td>\n                <td>工商江苏南京业务处理中心</td>
                <td><b>网点</b></td>
                <td>江苏徐州业务中心</td>
            </tr>
            <tr>
                <td colspan="2"><b>币种</b></td>
                <td>人民币</td>
                <td colspan="2"><b>钞汇标志</b></td>
                <td>钞票</td>
            </tr>
            <tr>
                <td colspan="2"><b>金额</b></td>
                <td>1.00元</td>
                <td colspan="2"><b>手续费</b></td>
                <td>0.57元</td>
            </tr>
            <tr>
                <td colspan="2"><b>合计</b></td>
                <td colspan="4">人民币(大写):壹圆整</td>
            </tr>
            <tr>
                <td colspan="2"><b>交易时间</b></td>
                <td>2017年6月1日</td>
                <td colspan="2"><b>时间戳</b></td>
                <td>2017.05-01-13.00.00,00000</td>
            </tr>
        </table>
    </div> <br>
    <div style="border: 1px">
        票据打印时间:2017-06-01 &nbsp;15:00:12 <br> <br>
        <s>票据打印单位:江苏徐州业务中心</s> <br> <br>
        操作员:大曾
    </div>
</body>
</html>
```

**表格要点：**
- `colspan="2"`：单元格横向合并 2 列
- `rowspan="4"`：单元格纵向合并 4 行（用于「收款人」「付款人」标题）
- `<b>`：加粗显示标签
- `<s>`：删除线（打印单位已作废）
- `&nbsp;`：空格占位

## 四、小结
本次作业练习了 HTML 中**表单控件**与**表格布局**两大基础能力。表单部分要掌握各类 `input` 类型与 `select`、`textarea` 的用法；表格部分要熟练使用 `colspan`、`rowspan` 进行单元格合并，这是还原单据、报表类页面的关键。

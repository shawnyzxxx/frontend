# 第二次作业：HTML + CSS 页面样式练习

## 文章导读
本篇是前端第二次作业，通过多个 HTML 页面练习 **CSS 盒模型、定位、伪类、表格布局、表单** 等样式技能，包括导航栏、登录页、菜单列表与修改密码页。适合 HTML/CSS 基础学习者巩固样式布局的读者。

## 一、作业说明
本作业包含三个页面：
1. **作业1**：制作带阴影、圆角的游戏导航栏，练习盒模型与 `:hover` 伪类
2. **作业2.1**：制作用户登录页面，练习背景图与表单
3. **作业2.3**：制作带侧边菜单的「修改密码」页面，综合练习定位、列表与表单

## 二、作业1：游戏导航栏
使用 `div` + `span` 制作导航栏，通过 CSS 实现边框、阴影、圆角和悬停效果。

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>作业1</title>
    <style>
        div {
            width: 800px;
            height: 40px;
            border-width: 1px;
            /* 元素本身 */
            margin: auto;
            border-color: black;
            border-style: solid;
            text-align: center;
            line-height: 2.5;
            background-color: black;
            box-shadow: 10px 10px 10px gray;
            border-radius: 15px;
        }
        span:hover {
            background-color: red;
        }
        span {
            /* 内联元素，宽度自动适应内容，需变形 */
            display: inline-block;
            color: white;
            height: 40px;
            width: 50px;
            text-shadow: 10px 10px 10px gray;
        }
    </style>
</head>
<body>
    <div>
        <span><b>游戏1</b></span>
        <span><b>游戏2</b></span>
        <span><b>游戏3</b></span>
        <span><b>游戏4</b></span>
        <span><b>游戏5</b></span>
        <span><b>游戏6</b></span>
        <span><b>游戏7</b></span>
        <span><b>游戏8</b></span>
        <span><b>游戏9</b></span>
    </div>
</body>
</html>
```

**关键样式点：**
- `display: inline-block`：让行内元素 `span` 具备宽度，方便设置样式
- `box-shadow`：盒子阴影
- `border-radius`：圆角
- `span:hover`：鼠标悬停时改变背景色（伪类）
- `line-height`：控制行高，实现文字垂直居中

## 三、作业2.1：用户登录页面
使用表格布局，配合背景图制作登录界面。

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>作业2.1</title>
    <style>
        [class] {
            position: relative;
            left: 100px;
        }
        .text {
            position: relative;
            left: 240px;
        }
        [id] {
            color: gray;
        }
    </style>
</head>
<body>
    <table border="0px" width="1000px" height="420px" cellspacing="0px">
        <tr>
            <td colspan="2" height="60px">
                <img src="http://zswxyjw.yinghuaonline.com/znlykjdxswxy_jsxsd/framework/images/index/index_02.png" alt="" height="60px">
            </td>
        </tr>
        <tr>
            <td width="500px" height="300px">
                <img src="./图片/涉外.png" alt="" width="500px" height="300px">
            </td>
            <td style="background-image: url(./图片/中南.png); text-align: center;">
                <big><big>用户登入</big></big><br>
                <form action="http://zswxyjw.yinghuaonline.com/znlykjdxswxy_jsxsd/framework/xsMain.jsp" method="post">
                    <p>用户名: <input type="text"></p>
                    <p>密码:&nbsp;&nbsp;&nbsp;&nbsp;<input type="password" name="password" id="password" value="" required></p>
                    <p>
                        <button type="submit" style="background-image: url(./图片/按钮.png); background-size: contain; width: 40px; height: 40px;" class="submit"></button>
                        <button type="submit" style="background-image: url(./图片/问号.png); background-size: contain; width: 40px; height: 40px;" class="submit"></button>
                    </p>
                </form>
            </td>
        </tr>
        <tr>
            <td id="">湖南强智科技发展有限公司&nbsp;版权所有</td>
            <td class="text" id="">隐私声明|设为首页</td>
        </tr>
    </table>
</body>
</html>
```

**关键样式点：**
- `position: relative` + `left`：相对定位微调元素位置
- `background-image`：背景图，配合 `background-size: contain` 按图片比例适应
- `required`：表单必填校验
- `[class]`、`[id]`：属性选择器

- `disabled`：禁用输入框
- `<hr>`：列表项分隔线
